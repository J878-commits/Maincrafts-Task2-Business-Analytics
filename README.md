# Management-Level Sales Performance Dashboard (Excel + Power BI)

## 📌 Project Overview
This project was completed as part of Task 2 of the **Maincrafts Technology Business Analytics Internship**. It transitions raw sales data into management-level executive analytics using dynamic DAX measures in Power BI Desktop and calculated KPIs in Microsoft Excel.

## 📊 Key Metrics & Highlights
* **Total Gross Sales**: $6.18M
* **Net Profit**: $1.61M
* **Overall Profit Margin**: 26.05%
* **Total Volume**: 12,745 units transacted

## 🛠️ Tools & Technologies Used
* **Microsoft Excel**: Data cleaning, calculated columns (`Profit Margin`, `Sales Category`), and pivot table baseline analysis.
* **Power BI Desktop**: Interactive dashboard visual design, slicers, custom visual styling, and dynamic DAX metrics.
* **DAX (Data Analysis Expressions)**: `Total Sales`, `Total Profit`, `Profit Margin`, and continuous `Monthly Sales` time-intelligence analysis.

## 📈 Dashboard Features
* **Executive KPI Cards**: Real-time business status snapshot across sales volume, earnings, and ROS ratio.
* **Regional Performance Analysis**: Bar chart highlighting top revenue and profit drivers (Florida, New York, California).
* **Category & Sub-Category Performance**: Donut chart and tabular view detailing high-margin drivers vs. high-volume products.
* **Time-Series Trends**: Line visual showing continuous monthly sales patterns and seasonal peaks.
* **Dynamic Slicers**: Instant filtering across Region/State, Category, and Order Date.
